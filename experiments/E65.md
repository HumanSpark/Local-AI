**What was asked:** put Opus through the instruments already built, as the cheap
half of H0 (Opus substitution). **What was actually run is NOT what was asked
for, and that is the first thing to read.**

### The arm is Opus 5 via a subagent harness, NOT Opus 4.7 via API

The owner asked for **Opus 4.7 specifically**. This arm cannot deliver it, for a
reason that is structural rather than an oversight:

- **No working cloud credential exists.** The vaulted
  `SPARKCORE_LLM_OPENROUTER_API_KEY` returns **HTTP 401 `User not found`** on
  both `/api/v1/key` and `/api/v1/credits` - revoked, not merely out of credit
  (that is a 402). No direct Anthropic route exists on this host either: no `ant`
  CLI, no `ANTHROPIC_*` env var, no `anthropic` SDK, no `~/.config/anthropic/`.
- **The subagent transport cannot pin a version.** Claude Code's Agent tool takes
  a model *alias* - `sonnet`/`opus`/`haiku`/`fable` - which resolves to the
  running session's model. That is **Opus 5**, a LATER model than the 4.7 asked
  for.

So this row is a **frontier upper bound**, not the Opus 4.7 measurement. The 4.7
question stays open and is blocked on one owner action: minting a key.

### The finding is about the INSTRUMENT, not the model (F91)

**L3-hard cannot discriminate a frontier model from the two best local arms.**
Three arms now sit at 12/12 with 12/12 citations. As a comparator for H0 the
instrument is **spent**, and no amount of re-running it will produce a number
that separates them.

**What this does NOT say, and the distinction is the whole point.** It does not
say the systems are equal. At n=12 with both arms at ceiling, a true difference
of up to roughly 25 percentage points would still show as 12/12 versus 12/12.
This is the same statistical objection registered against H0's proposed 5pp
threshold in AMENDMENT 2, and it applies to our own result as readily as to
someone else's: **a tie at ceiling is a statement about the ruler.**
