## E66 - the frontier arm on the held-out depth design: 18/20, the SAME as gpt-oss (2026-08-19)

Follow-on to E65, which established that L3-hard is saturated. This goes where a
local arm demonstrably fails: E63's `P3`.

**Same caveat as E65, and it has not gone away.** The arm is a frontier model
reached through Claude Code subagents, not Opus 4.7 through an API. No working
cloud credential exists and the Agent tool takes a model *alias*, not a version.
Upper bound, not the 4.7 measurement.

### Method

Both crossover orders were driven turn by turn - 18 turns each, one subagent per
arm, continued via SendMessage so the model's OWN answers accumulate in its
context exactly as `run_multiturn_eval.py` builds `messages`. Grading is the
repo's `grade_multiturn` against the same `turn["expect"]` blocks
(`tools/grade_heldout_subagent.py`).

**One deliberate harness difference, declared.** Each turn was delivered as a
FILE PATH for the subagent to read, not pasted inline. The conversation is
103,679 chars per arm and hand-transcribing it risks a silent drop in the middle
of a legal document - an error mode that is invisible and would corrupt
comparability. Reading the file makes the delivered bytes exact. The turn files
live in a scratch directory that contains no answer key; the keys are in
`spikes/ps-eval/`.

### The result

| | AB arm | BA arm | held-out total |
|---|---|---|---|
| **frontier (subagent)** | 12/13 | 12/13 | **18/20** |
| gpt-oss-120b (E63) | 12/13 | 12/13 | **18/20** |

Recent probes R1/R2/R3 correct in both arms (EUR 24,800 / 195,000 / 18,923), so
the deliveries were absorbed. No `wrong_document`, no `accepted_false`, no
non-termination, no transport failure.

### The two arms fail DIFFERENTLY, and that is the whole result

| question | gpt-oss-120b | frontier arm |
|---|---|---|
| `P3` shallow | `off_by_calendar` - **15 September 2026** | `off_by_calendar` - **15 September 2026** |
| `P3` deep | `off_by_calendar` - **15 September 2026** | **correct** - 14 September 2026 |
| `X1` shallow | correct | **wrong** - "YES" where the answer is NO |
| `X1` deep | correct | correct |

**The frontier arm produced the IDENTICAL wrong date to gpt-oss-120b.** Not a
different wrong answer, not a different failure mode - the same six-year
limitation period miscounted by the same one day to the same value. That is the
strongest evidence yet for **H6**: the defect is in the date arithmetic itself,
it is shared across models with nothing else in common, and it is not a
capability gap that a bigger model closes.

**But the frontier arm is NOT deterministic about it.** gpt-oss gave the same
wrong answer in both positions (F88's bit-determinism). This arm was wrong once
and right once on the same question. With **n=1 per cell** that difference cannot
be attributed to position rather than run-to-run variance, and this arm is
demonstrably not deterministic, so the honest reading is *sometimes wrong*, not
*wrong when shallow*.

### The depth axis does NOT transfer, and the deep 10/10 must not be read as robustness

E57/E63 measure degradation when the answer sits far back in a context that is
**67.3% full** (21,694 of 32,768 tokens for gpt-oss). A frontier model with a 1M
context sees the same conversation at roughly **2%** full. Its `deep` cells were
never under the pressure the instrument was built to apply, so "deep 10/10" here
is a statement about headroom, not about robustness. **On the axis this
instrument is named for, the comparison is not like-for-like** - the tier
separates local arms from each other and cannot be repurposed as a frontier
comparator without rebuilding it against a context the frontier model would
actually strain.

**Both of the frontier arm's failures were SHALLOW**, which is the opposite of a
depth-degradation pattern and is consistent with the headroom reading.

### Where this leaves H0

Two instruments run, and **neither separates the frontier arm from gpt-oss-120b**:
L3-hard 12/12 vs 12/12, held-out depth 18/20 vs 18/20. That is now a pattern
rather than a single saturated tier, and it is the substantive H0 result so far -
on this lab's document-reasoning instruments, at these sizes, no measurable gap.
What it is not is evidence of equality: the sample sizes make a gap of tens of
percentage points invisible, exactly as AMENDMENT 2 registered.
