## E36: cloud reference arms - the quantisation isolator and the frontier gap (2026-08-15, pre-registered)

**Two questions the local-only arms cannot answer.**

1. **What does OUR stack cost?** OpenRouter serves `qwen/qwen3.8-27b` - the
   SAME model, cloud-hosted, presumably unquantised. Running the identical
   task set against it isolates our Q4_K_M + Vulkan + gfx1151 from the model's
   inherent capability. Any gap is OUR deployment's cost, not the model's.
2. **Does cheap cloud already beat local?** That is the actual commercial
   question behind the routing guide, and it is not answerable from local
   numbers alone.

**Arms** (OpenRouter unless noted; ids verified against /api/v1/models):

| arm | id | $/Mtok in/out | why |
|---|---|---|---|
| same-model control | `qwen/qwen3.8-27b` | 0.45 / 3.20 | THE quantisation isolator |
| coding specialist | `poolside/laguna-s-2.1` | 0.09 / 0.18 | coding-house model, cheap |
| cheap generalist | `deepseek/deepseek-v4-flash-0731` | 0.14 / 0.28 | the "is local worth it" floor |
| GLM lineage | `z-ai/glm-5.2` | 0.49 / 1.54 | GLM-4.7-Flash is already a local fallback |
| frontier reference | `google/gemini-3.7-flash` | 0.375 / 1.875 | 1M ctx frontier-adjacent |
| cheap OpenAI | `openai/gpt-5.6-luna` | 0.10 / 0.60 | 1M ctx at commodity price |
| Mistral (direct API) | `codestral-latest`, `mistral-medium-latest` | est. | owner asked for Mistral specifically |

**Predictions (registered before the runs):**

1. **The same-model cloud control scores HIGHER than our local Q4_K_M** on the
   coding set, by **1-3 tasks of 15**. That gap IS the quantisation-plus-stack
   cost. **If the gap is 0, Q4_K_M costs nothing measurable on this task set**
   - a strong and quotable result for on-prem work.
2. **At least one sub-$0.30/Mtok cloud arm matches or beats our local
   Qwen3.8** on the coding set. If none does, local is genuinely competitive
   on capability-per-euro and not merely on privacy.
3. **The task set is at risk of saturating at the top.** A smoke run of
   `upstage/solar-pro4` (a cheap model) already scored **14/15** with the only
   miss on `eval_expr` rejecting malformed input. Registered consequence: if
   two or more cloud arms score >=14/15, the hard tier is not hard enough to
   locate the frontier and an EXPERT tier must be added before any cloud
   verdict is quoted. Local-vs-local comparisons remain valid regardless.

**Cost control:** OpenRouter reports authoritative per-call cost, which is
recorded per run. Hard ceilings in `CloudBudget`: $40 USD and 20M tokens, the
token ceiling existing because the Mistral price table is a hand-maintained
estimate and a wrong price must not overspend silently. Smoke run cost:
$0.0009 for 15 tasks, so the whole cloud programme is expected well under $5.

**Amendments:** none.
