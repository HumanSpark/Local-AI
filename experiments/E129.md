## E129 - the runtime upgrade, verified on the production gateway (2026-09-07)

sparkrouter's llama.cpp was upgraded from `067de9371` (build 9865, 2026-07-03)
to `daef7b687` (build 10712, 2026-08-31) at 17:32, by
`tools/upgrade_router_llama_binary.sh`. Binary only; no configuration changed.
Gateway down 14 seconds. Acceptance was health AND a real request through the
router, which returned `ok`.

Three requests against the live gateway afterwards, same prompt as E128:

| request | tokens | reasoning chars | outcome |
|---|---|---|---|
| no field | 404 | 775 | **identical to the old build** |
| `reasoning_effort: medium` | **640** | **1012** | honoured |
| `nonsense_level_xyz` | - | - | **HTTP 500**, template validation error |

### What each row establishes

1. **No regression for existing callers.** The default is byte-identical across a
   two-month runtime jump - 404/775 before and after. Whatever else changed
   upstream, what current consumers receive did not.
2. **The per-request path now works**, where E128 measured it silently ignored.
3. **The template validates on this build**, so `low`/`medium`/`xhigh` is the
   accepted set here and not merely on the bench build. That was the recorded
   precondition from the 08:03 outage, and it is met by measurement rather than
   carried over.

### The cross-check worth keeping

`medium` returns **640 tokens / 1012 reasoning chars**, which is exactly what the
bench worktree produced for this prompt at the same commit (E119 cell P, first
position of a fresh process). Same commit, different tree, different process,
different day - identical output.

That validates two things at once: the gateway build is equivalent to the bench
build rather than merely similar, and E119's numbers reproduce outside the
context that produced them. It also means bench figures measured on `daef7b6`
are now comparable to production, which was NOT true before the upgrade and is
the one good consequence of a change that was otherwise a cost.

**Still unmeasured:** whether anything else in the two-month jump changed
behaviour for the other two residents or for tool calling. One prompt on one
model is not a regression suite, and F57's class applies - figures measured on
the old gateway are not comparable to figures measured now.
