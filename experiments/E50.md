## E50: is the negative-branch defect a TOOL-CALL artefact or a REASONING defect? (2026-08-17, pre-registered before any run)

**Why this exists.** It is the only systematic failure this model has. Across
E33 and E45, on every predicate type tested, the model applies a conditional
flag **unconditionally**: it passes the branch where the flag should fire and
fails the branch where the correct action is to do nothing.

| pair | branch that fires | branch that must NOT fire |
|---|---|---|
| numeric (`c1`/`c2`) | 5/5 | **2/5** |
| date (`c4`/`c5`) | 4/5 | **0/5** |

**But every one of those observations is inside a TOOL CALL**, and E43 gives a
contrary signal from prose: matter `m12` asks whether a service credit counts
towards a liability cap, the answer is **no**, and the model said no - correctly,
at every sequence position E46 ran it at. So the same "the right answer is that
this does not apply" shape is failed in a tool call and passed in advice.

That difference decides how much the defect matters. If it is a tool-call
artefact, the guidance is "do not automate conditional actions" and advisory
work is unaffected. If it is a reasoning defect that the closed-record set
happens not to probe hard, it reaches the legal verdict directly - because
"this clause does not apply here" is a large fraction of what advice IS.

**ONE VARIABLE CHANGES: whether the model is asked to ACT or to ADVISE.** The
same conditions, the same facts, the same thresholds, expressed twice - once as
a tool-call instruction and once as a request for a written answer.

**Instrument.** A new prose tier, `tools/run_negative_branch.py`, carrying the
E45 conditional pairs restated as advisory questions, graded by exact match on
a sealed key. No LLM judge. Every pair keeps both branches, because a model
that always says "the rule does not apply" passes the negative branch and fails
the positive one, and only the pair separates capability from a fixed answer.

**Arms.** Qwen3.8-27B at `off`, `low`, `medium`; the workhorse as control. The
tool-call numbers from E45 are the comparison and are already measured.

### Predictions (registered before any arm runs). The FIELD is named in each.

1. **PRIMARY: `negative_branch_correct` in prose is at least 8/13 for Qwen3.8
   at `medium`**, against 2/13-equivalent in the tool-call setting. Registered
   as a positive because E43's `m12` and L2's `Z1` both show the model
   declining to apply something when it should not, in prose, reliably.
2. **The positive branch stays high: `positive_branch_correct` >= 11/13.** If
   this drops, the prose restatement has changed the task rather than the
   modality, and the experiment is void rather than informative.
3. **The gap between prose and tool-call negative-branch scores is at least 5
   points** for the same model at the same effort. This is the discriminating
   claim.
4. **The workhorse shows the same direction but a smaller gap.** It has no
   reasoning setting to raise, so registered at 4-9 on prose negative branches.
5. **`off` is materially worse than `low`/`medium` on negative branches.**
   Registered: `off` at least 3 below `medium`. F69 found `off` loses precedence
   and multi-hop while keeping retrieval, and "does this rule apply here" is
   closer to precedence than to retrieval.

**Falsifier: if prose negative-branch accuracy is also at or below 4/13, the
defect is a REASONING defect, not a tool-call artefact.** That would be the
most consequential negative result of the programme, because it would mean the
model is unreliable at exactly the judgement advisory work is made of, and the
legal verdict would need re-opening rather than confirming.
